# BigData_Project
# TITLE : Retail Sales Analytics and Demand Forecasting
This project implements an end-to-end data pipeline for analyzing retail sales data and forecasting future demand using big data and analytics tools.

# Technologies Used
HDFS
Apache Spark (PySpark & Spark MLlib)
Apache Hive
Apache Airflow
Tableau

# Project Objective
Store large retail data in HDFS
Clean and transform data using Spark
Generate features for forecasting
Train a machine learning model for demand prediction
Orchestrate the pipeline using Airflow
Visualize results using Tableau

# Workflow
HDFS → Spark ETL → Hive → Feature Engineering → Forecasting → Tableau

# Project Structure
BigData_Project/
 ├── Airflow/
 ├── spark_jobs/
 ├── Hive_queries/
 ├── Hadoop/
 ├── Tableau/
 └── README.md

# Output
Cleaned retail sales data
Forecasted sales results
Interactive Tableau dashboard
